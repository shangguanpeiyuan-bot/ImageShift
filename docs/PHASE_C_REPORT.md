# Phase C 验收报告

日期：2026-09-13。用户已授权继续 C/D；本阶段代码及当前可用平台验收完成，Android 设备验证仍有明确缺口。

## 交付

- 本地 JSON 设置库与前一完整版本备份、串行写入、损坏恢复和字段验证；不增加联网存储依赖。Windows 取实际 LOCALAPPDATA，Android 由平台返回 filesDir。
- 主题浅/深/跟随系统持久化；欢迎页只在首次启动显示。记住参数、输出目录、应用内完成提示、成功后打开目录、关闭历史等选项实际生效。
- 历史只保存时间、数量、成功/失败/取消数、字节统计、输出目录和可复用参数，不写图片、缩略图或原图路径；最多 200 条，可清空、复用参数、打开目录。
- 内置网页 JPG、高清 JPG、无损 WebP、1080p/4K 边界框预设，自定义保存/重命名/删除，上限 100。WebP 不展示虚假的有损质量值。
- Android 持续目录授权与使用前校验；失效时清空默认位置并提示重选。私有会话旧缓存超过 24 小时后按应用目录边界清理；发布失败/替换预览释放旧暂存，清空列表释放当前副本。禁止 Android 备份应用数据。
- Windows Ctrl+O、Ctrl+A、Delete、Ctrl+Enter、Esc 基础操作；输入框保留其编辑操作。桌面导航可滚动，手机导航接入历史/设置，任务与结果保持可达。
- 文件夹、剪贴板、系统通知等 P2 未加入；完成通知指应用内提示，不冒称系统通知。参数预设可保存完整流水线，源图片从不随预设或历史持久化。

## 自动与实际验证

全量 131 项测试通过、analyze 无问题（最终日志见 artifacts/phase-d）。其中新增 8 项本地库测试、13 项双平台页面/明暗布局和预设/主题交互测试；覆盖重启恢复、备份损坏恢复、并发保存、异常 schema/字段、历史清空、预设修改/删除、目录失效、真实任务汇总。

## 性能实测

硬件：Intel Core i7-13700H，14 核/20 线程，物理内存 16788430848 字节（约 15.64 GiB）。测试程序经 `dart compile exe tool/performance_check.dart` 编译 AOT，原创合成渐变素材，输出 JPEG 后独立读取、解码并验证尺寸。素材生成不计入转换耗时，RSS 为包括素材生成、解码校验的整个测试进程，不是 UI 应用的独立峰值。此数据不能代表所有相机照片或手机性能。

| 用例 | 实际结果 | 转换耗时 | 校验后进程 RSS |
| --- | --- | --- | --- |
| 3840×2160 PNG（4K） | 成功 | 6843 ms | 199335936 B |
| 4000×3000 PNG（12 MP） | 成功 | 11369 ms | 294240256 B |
| 6000×4000 PNG（24 MP） | 成功 | 15255 ms | 519503872 B |
| 7680×4320 PNG（8K） | 因超过 24 MP 上限拒绝 | 3 ms | 270467072 B |
| 4000×3000 TIFF | 成功 | 6493 ms | 295399424 B |
| 100 张 256×256 图片 | 全部成功，100 个独立输出 | 4677 ms | 进程累计峰值见下 |

全过程 RSS 高水位 619048960 B（约 590.37 MiB），包含生成 8K 素材。原始 JSON/log 保存在 artifacts/phase-c/performance.*，运行脚本可复测。8K 的拒绝是实际资源边界，不宣称支持 8K 转换。现有 128 MiB/24 MP/16384 px 限制继续保留；未证明能够杜绝所有 OOM。没有无界并发解码，检查/预览/转换共享单 CPU 槽。
