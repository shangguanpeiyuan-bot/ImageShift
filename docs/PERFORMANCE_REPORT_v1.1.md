# v1.1 开发期性能实测

2026-09-14，Windows x64，i7-13700H，16,788,430,848 B RAM。状态：Tested（合成素材，非 Android / UI 峰值）。每次转换独立 AOT 进程；生成和 FFmpeg 完整解码验证在进程外，峰值 RSS 来自 Dart ProcessInfo.maxRss。原始 JSON 与样本保存在被忽略的 artifacts/media-upgrade/benchmark。

两条路径读取同一个已保存的 FFmpeg 红蓝渐变输入，均输出 JPEG 质量 90。不同编码器不保证字节级或视觉质量完全等价。初次 fixture 使用随机默认梯度位置，原文件已保留；复测应直接复用这些文件。单次运行、无统计置信区间，不将缓存和合成素材成绩当作真实相册 KPI。
